# מייפלורז: המדריך העברי ל-MapleStory Classic

אתר סטטי בעברית (RTL) עם מדריכים מלאים למייפל סטורי קלאסיק, מערכת ניהול מובנית ומקומות מוכנים לפרסומות.

## איך זה עובד

- **התוכן** נמצא בקבצי Markdown בתיקייה `content/guides` (מדריכים) ו-`content/pages` (אודות, פרטיות).
- **ההגדרות** (שם האתר, קטגוריות, פרסומות, דומיין) נמצאות ב-`site.config.json`.
- **הבנייה** (`node build.mjs`) יוצרת את האתר המוכן בתיקייה `dist/`. אין תלויות חיצוניות.
- **GitHub Actions** בונה ומפרסם את האתר ל-GitHub Pages אוטומטית בכל שינוי.

## מערכת הניהול

נכנסים לכתובת `/admin/` באתר (למשל `https://dolmask.github.io/Maple-il/admin/`).

1. בפעם הראשונה צריך טוקן גישה מ-GitHub. המסך מסביר צעד אחר צעד איך יוצרים אותו (Contents: Read and write על המאגר הזה).
2. אחרי ההתחברות אפשר ליצור מדריך חדש, לערוך קיים, להעלות תמונות ולשנות הגדרות.
3. התצוגה המקדימה משתמשת באותו קוד בדיוק שבונה את האתר, כך שמה שרואים זה מה שמתפרסם.
4. לחיצה על **פרסום** שומרת את הקובץ במאגר, והאתר מתעדכן תוך כדקה-שתיים.

## תחביר מיוחד במדריכים

| תחביר | תוצאה |
|---|---|
| `{{lv 30}}` | תג רמה בסגנון המשחק |
| `:::tip כותרת` … `:::` | תיבת טיפ (גם `warning`, `info`) |
| `:::npc שם (Name)` … `:::` | בועת דיבור של NPC |
| `:::stats כותרת` + שורות `מפתח: ערך` + `:::` | כרטיס נתונים כהה |
| `[[ad]]` | מקום לפרסומת (אחרת נכנסת אוטומטית לפני הכותרת השלישית) |

## הפעלת פרסומות

1. פותחים חשבון ב-Google AdSense ומגישים את האתר לאישור (עדיף עם דומיין פרטי).
2. במערכת הניהול ← **הגדרות האתר ופרסומות**: מסמנים "להציג פרסומות" ומדביקים את ה-Publisher ID (`ca-pub-…`).
3. קובץ `ads.txt` ומדיניות הפרטיות כבר מוכנים.

## דומיין פרטי

בהגדרות ממלאים את הדומיין (למשל `www.example.co.il`) ואת כתובת האתר המלאה. אצל רשם הדומיין מוסיפים רשומת CNAME שמפנה ל-`dolmask.github.io`. ב-GitHub: Settings ← Pages ← Custom domain.

## דירוג השחקנים

העמוד `/ranking/` מציג את דירוג השחקנים מ-[ClassicRank](https://classicrank.com). הנתונים נמשכים בכל בנייה (`scripts/fetch-ranking.mjs`), ו-GitHub Actions בונה מחדש כל 30 דקות.

- **בלי מפתח** (ברירת המחדל): 1,000 השחקנים המובילים לפי רמה ו-1,000 לפי Fame. הסינונים פועלים בתוך הרשימה הזו.
- **עם מפתח Partner**: מבקשים ב-[classicrank.com/developer](https://classicrank.com/developer) (התחברות עם Discord). את המפתח שמים **רק** ב-GitHub ← Settings ← Secrets and variables ← Actions ← New repository secret, בשם `CLASSICRANK_KEY`. אז נמשכים עד `ranking.maxRows` שחקנים (ברירת מחדל 10,000), וגם לשוניות "אי ההתחלה" ו"מתחילים לנצח".
- **אם ClassicRank לא זמין**, הבנייה משתמשת בנתונים הקודמים מהאתר החי, והאתר לא נשבר.
- **כיבוי**: `"ranking": { "enabled": false }` ב-`site.config.json`.
- **חובה לפי התנאים שלהם**: קישור גלוי ל-classicrank.com בכל עמוד שמציג את הנתונים. זה כבר בנוי בעמודים.

## פיתוח מקומי

```bash
node build.mjs
cd dist && python3 -m http.server 8000
```

בדיקה מקומית של הדירוג עם נתוני דוגמה (לא נפרסים): `RANKING_FIXTURE=test/fixtures/ranking-sample.json node build.mjs`. בנייה בלי רשת: `RANKING_OFFLINE=1 node build.mjs`. בדיקות: `node --test test/*.test.mjs`.

# דירוג שחקנים — תוכנית ביצוע

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** עמוד דירוג `/ranking/` ועמוד שחקן `/ranking/player/` באתר מייפלורז, מנתוני ClassicRank, בעיצוב הקיים.

**Architecture:** סקריפט בזמן הבנייה מושך את ה-API וכותב `dist/ranking/data.json` דחוס. מודול משותף (`src/lib/ranking-data.js`) מכיל את מיפוי המקצועות, פריסת הנתונים, סינון, מיון ועימוד, ומשמש גם את הבנייה וגם את הדפדפן (`assets/lib/`). `render.js` בונה את המעטפת, ו-`src/assets/ranking.js` (ES module) מצייר את הטבלה.

**Tech Stack:** Node 20, בלי תלויות, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-14-ranking-design.md`

## Global Constraints
- בלי תלויות npm. הבנייה נשארת `node build.mjs`.
- הבנייה לא נכשלת בגלל הדירוג: אם אין נתונים, היא כותבת `{"meta":{...,"empty":true},"rows":[],"jobs":[]}`.
- `CLASSICRANK_KEY` נקרא רק מ-`process.env`, ולא נכתב לשום קובץ.
- קישור גלוי ל-`https://classicrank.com` בכל עמוד דירוג.
- 25 שורות בעמוד. כל הטקסטים בעברית.
- ריווח בין בקשות בלי מפתח: לפחות 2,100 מ"ש (30 בקשות לדקה).

## Review Focus
- שם עם אותיות גדולות/קטנות או רווחים (`?name=insomnialk`): צריך להימצא בלי תלות ב-case. → בדיקה ב-Task 1 (`findPlayer`).
- `?page=` מחוץ לטווח, שלילי או טקסט: צריך להיצמד לטווח 1..pages. → Task 1 (`paginate`).
- מקצוע לא מוכר מה-API (למשל ג'וב שלישי חדש): מוצג בשם האנגלי, במשפחה "אחר", ולא מפיל את העמוד. → Task 1 (`jobInfo`).
- הסינון "טווח רמות" עם min>max: הערכים מתחלפים. → Task 1 (`filterRows`).
- שם עם HTML (`<img onerror>`): מוצג כטקסט. → Task 4 (escape בכל ציור).

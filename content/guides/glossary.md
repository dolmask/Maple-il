הצ'אט של מייפל מלא בקיצורים. הנה המילון, מסודר לפי נושא. המונחים נשארים באנגלית, כי ככה תראו אותם במשחק.

## כללי

| מונח | פירוש |
|---|---|
| MS | MapleStory |
| MSCW / MS Classic | MapleStory Classic World, העולם הקלאסי הרשמי של Nexon |
| pre-BB | מייפל של לפני עדכון ה-Big Bang ב-2010 |
| Big Bang | העדכון של 2010 שחילק את ההיסטוריה של מייפל ל"לפני" ו"אחרי" |
| GMS / KMS / JMS / EMS | הגרסאות הגלובלית, הקוריאנית, היפנית והאירופית |
| OSMS / Old School | סלנג למייפל הישן. שימו לב שהמכניקה בעולם הקלאסי לא זהה לו |

## רמות ו-EXP

| מונח | פירוש |
|---|---|
| EXP | נקודות ניסיון, מהריגת מפלצות וממשימות |
| grind | להרוג מפלצות שוב ושוב בשביל EXP |
| ding | לעלות רמה |
| train | קבוצה שמתאמנת ביחד באותה מפה |
| leech | שחקן ברמה נמוכה בפארטי חזק שמקבל EXP בלי לעשות הרבה |
| PL / power level | עליית רמות מהירה, בדרך כלל בעזרת חבר חזק |
| party bonus | בונוס EXP לפארטי, לפי מספר החברים |
| mob rate | כמה מפלצות המפה מחזיקה |
| respawn wave | הגל שבו המפלצות חוזרות, כל ~7.56 שניות |

## מקצועות

| מונח | פירוש |
|---|---|
| Beginner | מתחיל, עד Lv 10 |
| 1st / 2nd / 3rd job | ג'וב ראשון (Lv 10), שני (Lv 30), שלישי (Lv 70, עוד לא במשחק) |
| branch | ענף: אחד מעשרת המסלולים בג'וב השני |
| job advancement | הקידום אצל ה-NPC |
| pure | כל ה-AP לסטט הראשי |
| dexless / strless / lukless | לוותר על הסטט המשני ולהסתמך על ציוד לדרישות |
| hybrid | לחלק AP בין הסטט הראשי והמשני |
